parble renders its wooden marble runs with WebGPU, and this browser did not give the page a WebGPU adapter. There is no WebGL version.

Browsers that run it

  • Chrome or Edge 113+macOS, Windows, ChromeOS
  • Safari 26+macOS, iOS, iPadOS
  • Firefox 141+Windows; later versions on macOS
Try again

Already on one of these? Check that hardware acceleration is turned on in the browser's settings, then try again.
